Sparkleen **0.0.1 Android preview** untuk pengujian manual, bukan rilis produksi.

- Sesi bertahan ketika koneksi/backend sementara tidak tersedia, dengan layar retry.
- Refresh profil/poin/pesanan/notifikasi saat pull-to-refresh dan kembali dari background.
- Biometrik kuat Android untuk membuka sesi tersimpan dan, secara opsional, membuat tagihan.
- Font Manrope/Plus Jakarta Sans dibundel agar gaya tampilan tetap sama saat offline.
- Pengaturan server lokal tersedia pada versi preview. Login pertama tetap memakai PIN akun.

**Cara menguji di HP**

1. Pasang `Sparkleen-0.0.1-preview.apk`. Izinkan instalasi dari browser/file manager bila Android meminta.
2. Jalankan backend Laundry terbaru pada laptop: branch `feat/notifications-loyalty`, jalankan migrasi yang diperlukan, dan gunakan database pengujian.
3. Jalankan server lokal yang bisa dijangkau HP (contoh CodeIgniter: `php spark serve --host 0.0.0.0 --port 8080`). Izinkan port pengujian pada firewall, dan sambungkan HP/laptop ke Wi-Fi sama.
4. Pada layar login APK, pilih **Atur server laptop**. Isi IP Wi-Fi laptop, misalnya `http://192.168.1.10:8080`, tanpa `/api/v1`. `10.0.2.2` hanya untuk emulator, bukan IP laptop di HP fisik.
5. Login memakai akun pengujian yang dibuat/diaktivasi pada backend tersebut.
6. Aktifkan **Profil → Keamanan dan biometrik** setelah mendaftarkan sidik jari pada pengaturan Android.

**Batas versi preview**

- Package: `com.sparkleen.sparkleen_mobile.preview`, minimum Android 7 (API 24).
- APK memakai mode release untuk performa tetapi **ditandatangani dengan debug key untuk pengujian**, bukan signing produksi. Build ulang oleh lingkungan lain mungkin perlu uninstall preview lama; uninstall menghapus pengaturan lokal.
- Biometrik memerlukan sesi backend yang masih berlaku dan sensor biometrik kuat. Logout/ganti server menghapus preferensi sesi. Setelah satu menit di background, sesi biometrik dikunci kembali.
- Konfirmasi biometrik adalah perlindungan lokal sebelum membuat tagihan. Ini tidak membuktikan pembayaran uang nyata; backend tetap menentukan status pembayaran.
- Pembayaran tetap **SIMULATION**. Jangan transfer uang nyata. Push OS/FCM belum tersedia.
- HTTP hanya diizinkan pada flavor preview untuk pengujian LAN. Gunakan data akun pengujian dan jaringan yang dipercaya. Produksi memerlukan HTTPS dan signing milik pemilik aplikasi.
- Sensor fisik, secure storage native, dan perilaku lifecycle Android masih memerlukan uji pada HP pemilik; lulus tes otomatis bukan jaminan bebas bug.

Validasi otomatis: analyzer bersih, 149 tes Flutter lulus, satu skenario integrasi HTTP Dart/PHP/MariaDB lulus, build APK Android berhasil, identitas paket/aset dan tanda tangan APK diperiksa. Sensor fisik tetap perlu diuji manual.

Uji: buka kembali saat jaringan mati → retry saat koneksi pulih; update poin dari kasir → refresh/resume; coba biometrik sukses/batal/terkunci, termasuk membatalkan lalu mengulangi prompt; logout/ganti akun/ganti server; background >1 menit; tema terang/gelap; teks besar; verifikasi nominal sebelum membuat tagihan simulasi.
